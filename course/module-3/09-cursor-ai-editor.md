# Lesson 3.09 — Cursor: An Editor Built Around AI

## What You'll Learn

VS Code with Copilot is like a car with a GPS bolted on. Cursor is a car where the GPS is built into the dashboard from the start. It's VS Code, but rebuilt with AI at the center of everything.

---

## What Makes Cursor Different

With Copilot, AI suggests code as you type. With Cursor, you can:

- Chat with your entire codebase and ask it questions.
- Highlight any code and ask AI to explain or change it.
- Press a shortcut, describe what you want, and have the edit happen right in the file.

It's more like having a conversation with your project.

---

## Do This First

**Step 1 — Download Cursor**

Go to [cursor.sh](https://cursor.sh) and download it for your operating system. Install it.

**Step 2 — Open your project**

Open Cursor. Go to **File > Open Folder** and open your project folder.

**Step 3 — Use Ctrl+K**

Press `Ctrl+K` (or `Cmd+K` on Mac). A small input bar will appear at the top of your editor.

Type:

```
change the heading in my HTML file to say "My AI Project"
```

Press Enter. Cursor will find your HTML file, locate the heading, and make the change — directly in the file.

---

## Cursor Also Has a Chat Panel

Press `Ctrl+L` to open the chat panel on the right side. You can ask it anything about your project:

- "What does this function do?"
- "Where is the bug in this file?"
- "Rewrite this in a simpler way."

It reads your files automatically. You don't have to paste code in.

---

## Cursor vs. VS Code + Copilot

Both are great. VS Code + Copilot is more familiar if you already know VS Code. Cursor is faster for people who want to work primarily through conversation.

Try both and see what feels right.
