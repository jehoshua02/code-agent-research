# Lesson 3.02 — Chat-Based Coding: Using ChatGPT to Write Code

## What You'll Learn

You don't have to write code from scratch. You can just ask an AI to write it for you.

This sounds almost too easy. But it works. Let's try it right now.

---

## Do This First

1. Go to [chat.openai.com](https://chat.openai.com) and sign in (free account works).
2. Type this exactly:

```
Write Python code that asks my name and says hello.
```

3. You'll get back something like this:

```python
name = input("What's your name? ")
print("Hello, " + name + "!")
```

4. Copy that code.
5. Go to [replit.com](https://replit.com) and create a free account.
6. Create a new Python project.
7. Paste the code in. Hit **Run**.

If it says `Hello, [your name]!` — you just ran AI-generated code.

---

## What Just Happened

You asked for something in plain English. The AI turned it into real, working code.

That's chat-based coding. No setup. No manual. Just ask.

---

## Why This Is Useful

Most beginners spend hours trying to figure out syntax — the exact way code has to be written. With chat-based coding, you skip that part. You describe what you want, and the AI handles the syntax.

You still need to understand what the code does. But you don't have to remember every tiny detail by heart.

---

## One Thing to Watch Out For

AI code isn't always perfect. Sometimes it makes small mistakes. Sometimes it uses things you haven't learned yet.

That's fine. The next lessons will teach you how to fix it.
