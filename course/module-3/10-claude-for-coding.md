# Lesson 3.10 — Claude for Coding: Long Context, Careful Answers

## What You'll Learn

You've already learned about Claude in Module 2. Claude is an AI made by Anthropic. It's especially good at handling large amounts of code and giving clear, well-explained answers.

This makes it really useful when you want to understand what code actually does — not just have it written for you.

---

## What "Long Context" Means

In Module 2, you learned about context windows — how much text an AI can hold in its head at once.

Claude has a very large context window. That means you can paste in an entire file — hundreds of lines — and it can read and understand all of it at once. Many other tools can't do this without getting confused.

---

## Do This First

1. Open your HTML file from Module 1 (or any HTML file you have).
2. Select all the text and copy it.
3. Go to [claude.ai](https://claude.ai) and sign in (free account works).
4. Paste your entire HTML file into the chat.
5. Then type:

```
What does each line do?
```

6. Read the response.

Claude will walk through your file section by section and explain what each part does in plain English.

---

## When to Use Claude vs. ChatGPT

There's no strict rule. But here are some rough guidelines:

- **Claude** — explaining code, reviewing big files, careful step-by-step explanations.
- **ChatGPT** — quick code generation, general questions, brainstorming.

Try both and form your own opinions. Different tools click differently for different people.

---

## Claude Is Also Honest About Uncertainty

If Claude doesn't know something, it usually says so instead of making something up. That's useful when you're debugging — you don't want confidently wrong answers.
