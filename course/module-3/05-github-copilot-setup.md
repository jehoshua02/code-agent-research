# Lesson 3.05 — GitHub Copilot: AI That Lives in Your Editor

## What You'll Learn

ChatGPT lives in a browser tab. GitHub Copilot lives inside your code editor. It watches what you type and suggests the next lines automatically — like autocomplete on your phone, but for actual code.

---

## What Is GitHub Copilot?

Copilot is made by GitHub (which is owned by Microsoft). It's trained on a huge amount of code and has seen patterns from millions of projects.

When you start typing something, Copilot guesses what you're trying to do and shows you a suggestion in gray text. Press Tab to accept it. Keep typing to ignore it.

---

## Do This First — Get Copilot for Free

Students get Copilot free. Here's how:

**Step 1 — Get a GitHub account**

If you don't have one, go to [github.com](https://github.com) and sign up.

**Step 2 — Apply for the Student Pack**

Go to [education.github.com/pack](https://education.github.com/pack). Click **Sign up for Student Developer Pack**. You'll need to verify you're a student — a school email or photo of a student ID works.

(This can take a day or two to approve. Keep going with the rest of this lesson while you wait.)

**Step 3 — Install VS Code**

Go to [code.visualstudio.com](https://code.visualstudio.com) and download VS Code for your operating system. Install it.

**Step 4 — Install the Copilot Extension**

1. Open VS Code.
2. Click the Extensions icon on the left sidebar (it looks like four squares).
3. Search for **GitHub Copilot**.
4. Click **Install**.
5. Sign in with your GitHub account when it asks.
