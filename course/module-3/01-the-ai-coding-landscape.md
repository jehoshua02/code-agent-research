# Lesson 3.01 — The AI Coding Landscape

## What You'll Learn

There are a lot of AI coding tools out there. They're not all the same. Some help you chat and write code. Some live inside your editor and suggest things as you type. Some can build an entire app from a description.

This lesson gives you the map.

---

## The Four Types of AI Coding Tools

**Chat tools** — You open a website, type a question, and get code back. ChatGPT and Claude work this way. No setup needed.

**Autocomplete tools** — These live inside your code editor and watch what you type. When they think they know what comes next, they suggest it. GitHub Copilot is the big one.

**UI generators** — You describe what a website or app should look like, and the AI builds the design for you. v0 by Vercel does this.

**AI-first editors** — These are full code editors with AI baked in everywhere. You can chat with your code, ask it to make changes, and have full conversations about your project. Cursor is the main example.

---

## Why Does This Matter?

Think of it like gaming peripherals. A mouse, a keyboard, and a controller all let you play games, but they're built for different things. You wouldn't use a controller to play a strategy game on PC.

AI tools are the same. Different tools for different jobs. This module teaches you all of them.
