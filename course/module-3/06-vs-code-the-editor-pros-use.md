# Lesson 3.06 — VS Code: The Editor Pros Use

## What You'll Learn

VS Code is the most popular code editor in the world. It's free, fast, and runs on Windows, Mac, and Linux. Almost every professional developer uses it or something very close to it.

Now that you've installed it, let's actually use it.

---

## Do This First

1. Open VS Code.
2. Go to **File > Open Folder**.
3. Open your `myproject` folder — the one you've been using since Module 1. If you don't have it, create a new empty folder anywhere and open that.

---

## What You're Looking At

VS Code has three main areas:

**File Tree (left side)**
This shows all your files and folders. Click a file to open it.

**Editor (center)**
This is where you type your code. It highlights different parts in different colors to make it easier to read — that's called syntax highlighting.

**Terminal (bottom)**
You can open a terminal right inside VS Code. Go to **Terminal > New Terminal**. This is the same terminal you learned in Module 1, just built in.

---

## Why Not Just Use Replit?

Replit is great for quick experiments. VS Code is what you use when you're building something real.

Think of it like this: Replit is a food court. VS Code is your own kitchen. The food court is easy and fast. But if you want to cook something serious, you need your own setup.

---

## A Few Useful Things to Know

- Press `Ctrl+S` (or `Cmd+S` on Mac) to save.
- Press `Ctrl+`` ` (backtick) to open and close the terminal.
- Press `Ctrl+P` to search for any file by name.

You don't need to memorize these. You'll learn them naturally as you use them.
