# Lesson 3.03 — Replit: Your Browser-Based Coding Home

## What You'll Learn

Installing coding tools is annoying. You have to download stuff, configure things, and sometimes it just breaks. Replit skips all of that. You write and run code directly in your browser, like Google Docs but for code.

---

## Do This First

1. Go to [replit.com](https://replit.com).
2. Create a free account.
3. Click **+ Create Repl**.
4. Choose **Python** as the language.
5. Name it whatever you want.
6. Click **Create Repl**.

You'll see three panels: a file tree on the left, a code editor in the middle, and a console on the right.

---

## Paste and Run

1. In the editor, paste in the code from last lesson:

```python
name = input("What's your name? ")
print("Hello, " + name + "!")
```

2. Click the green **Run** button at the top.
3. The console on the right will ask for your name. Type it and hit Enter.

That's it. Code running in a browser with zero installs.

---

## Why Replit Is Great for Learning

- Works on any computer, even a school Chromebook.
- Your projects are saved online automatically.
- You can share your project with a link — no file attachments.
- It has a built-in AI assistant too (but we'll use other tools for that).

---

## What Replit Can't Do

Replit is great for learning and small projects. For bigger, real-world apps, most developers eventually switch to their own computer setup. But that's way later. For now, Replit is your home.
