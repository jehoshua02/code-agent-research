# Lesson 3.13 — Your First AI-Built App (Part 2: Build)

## What You'll Learn

You have a plan. Now you give it to an AI and get actual code back. This is the part where your idea turns into something that runs.

---

## Do This First

1. Open your `idea.md` file. Copy your 3-sentence description.
2. Open Cursor or ChatGPT (your choice).
3. Type this prompt, with your description at the end:

```
Write the full Python code for this app. Include comments explaining what each section does. Make sure it actually runs with no errors.

[paste your description here]
```

4. Copy the code you get back.
5. Create a new file in your project called `app.py`.
6. Paste the code in and save it.
7. Run it in the terminal: `python app.py`

---

## If It Doesn't Run

That's completely normal. Don't panic.

- Copy the error message.
- Go back to the AI.
- Say: "I got this error. Can you fix it?" and paste the error.
- Apply the fix. Run again.

Most first attempts need one or two rounds of fixing. That's part of the process.

---

## Read the Code Before You Move On

Don't just run it and move on. Spend two minutes reading through it.

You don't have to understand every single line. But try to follow the basic flow:
- Where does the code start?
- Where does it ask for input?
- Where does it show the result?

You built this with AI. But you should still understand it well enough to describe it to someone else.

---

## What If the AI Makes Something Too Complicated?

Ask it to simplify. Say:

```
Can you rewrite this in a simpler way? I'm a beginner. Use basic Python only.
```

AI often defaults to showing off. You can always ask it to dial it back.

---

## What's Next

You have a working (or almost working) app. The next step is to fix what's broken and add what's missing. That's called iteration — and it's how all real software gets built.
