# Lesson 3.12 — Your First AI-Built App (Part 1: Plan)

## What You'll Learn

Before you write any code — or ask AI to write it — you need a clear description of what the app should do. If you describe it vaguely, you'll get vague code. Clear in, clear out.

This lesson is about making a plan. No coding yet.

---

## What Makes a Good App Description

A good description answers three questions:

1. **What does it do?** The core feature, in one sentence.
2. **Who uses it?** Just you? Friends? Anyone?
3. **What should it look like or output?** What happens when it runs?

You don't need all the answers to start. But you need enough for AI to understand the idea.

---

## Ideas If You're Stuck

Pick one of these or make up your own:

- A quiz that asks you 5 trivia questions and scores you.
- A password generator that creates random strong passwords.
- A countdown timer that tells you how many days until your birthday.
- A random compliment generator.
- A simple calculator for splitting a restaurant bill.

Keep it small. One screen, one purpose. You can always add more later.

---

## Do This First

Write a 3-sentence description of a simple app you want to build. Cover:

- What it does
- What the user types in (if anything)
- What it shows or prints as output

Example:

> This app asks you how much the restaurant bill is and how many people are splitting it. Then it asks if you want to add a tip. It tells you how much each person owes, including the tip.

1. Write your 3 sentences.
2. Create a new file in your project called `idea.md`.
3. Paste your description in and save it.

---

## Why This Step Matters

Skipping the plan and jumping straight to AI is like Googling "how to build a house" without knowing how many rooms you need. You'll get results, but they won't be yours.

A clear idea makes every step after this faster and less frustrating.
