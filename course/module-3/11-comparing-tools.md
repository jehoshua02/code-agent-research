# Lesson 3.11 — Comparing Tools: Same Task, Different Tools

## What You'll Learn

Every AI tool has trade-offs. Speed, accuracy, how it explains things, how much it costs, what it's best at. The only way to really understand them is to use them side by side.

---

## Do This First

Give this exact task to three different AI tools:

```
Write a Python function that takes a list of numbers and returns only the even ones.
```

Send it to:
1. **ChatGPT** (chat.openai.com)
2. **Claude** (claude.ai)
3. **Copilot** in VS Code (type it as a comment in a .py file)

After each one gives you an answer, write one sentence about what you noticed. It doesn't have to be technical. Just your honest reaction.

Examples of the kind of thing you might notice:
- "ChatGPT gave me extra explanation I didn't need."
- "Claude's version had comments in the code."
- "Copilot was faster but didn't explain anything."

---

## Things to Compare

When you look at the three answers, pay attention to:

- **Did it work?** Copy each version into Replit and run it.
- **Was it explained?** Did the AI tell you what the code does?
- **How long was the response?** Was it too short? Too long?
- **How confident did it seem?** Did it hedge, or just give you the answer?

---

## There's No Single Winner

Every developer has their preferred tools. Some people use ChatGPT for everything. Others swear by Claude. Some live in Cursor and barely use chat tools at all.

The goal isn't to find the "best" tool. It's to know what each one is good at so you can pick the right one for the job.
