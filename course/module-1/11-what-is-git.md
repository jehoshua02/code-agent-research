# Lesson 1.11 — What Is Git?

## The Big Idea

Git is a tool that tracks every change you make to your code — forever.

Not just "undo" like Ctrl + Z. Git saves snapshots of your entire project. You can go back to any snapshot, anytime, even weeks later. You can see exactly what changed, when, and why.

## Think About It This Way

Imagine you're building a Minecraft world. Every hour, you save a copy of the world to a different slot. If a creeper blows up your house tomorrow, you can load the save from two hours ago. No problem.

Git is exactly that, but for code. Every time you save a snapshot (called a commit), Git stores the entire state of your project. You can always go back.

## Why Developers Use Git Every Single Day

Without Git, coding goes like this:
- You change something.
- It breaks.
- You have no idea what you changed.
- You start over.

With Git, coding goes like this:
- You change something.
- It breaks.
- You check what changed.
- You revert to the last working version.
- You figure out what went wrong.

Git also lets multiple people work on the same project without destroying each other's work. That's how every app, game, and website you use was built — teams of people, all using Git.

## Git vs. GitHub — Not the Same Thing

This trips people up constantly.

- **Git** is the tool installed on your computer. It tracks changes locally.
- **GitHub** is a website where you store your Git history online — like cloud backup, plus social features.

You use Git on your computer. You push to GitHub so your code is backed up and shareable.

Today we're just setting up GitHub. Git installation comes next lesson.

## Activity: Create a GitHub Account

**Step 1:** Go to [github.com](https://github.com).

**Step 2:** Click "Sign up."

**Step 3:** Follow the steps. Use an email you actually check. Pick a username you'd be OK with people seeing — developers use GitHub like a portfolio.

**Step 4:** Verify your email and finish setup.

That's it. Your GitHub account is where your code will live online. Every project you build can go there.

Take a look around. You'll see repositories (repos for short) — those are projects. Each one has files, commit history, and more.

## Quick Recap

- Git tracks every change to your code as snapshots called commits.
- You can go back to any commit at any time.
- Git is local (your computer). GitHub is the cloud version.
- GitHub is also used as a coding portfolio.
