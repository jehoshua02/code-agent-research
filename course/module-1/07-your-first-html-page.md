# Lesson 1.07 — Your First HTML Page

## The Big Idea

Every website you have ever seen is built on HTML. The YouTube homepage. Instagram. Google. They all start with HTML.

HTML is not really a programming language — it's more like a skeleton. It tells the browser what content is on the page and how to organize it. Today you're going to build your first one.

## Think About It This Way

Imagine a house. Before you paint walls or decorate, you need a frame — the basic structure that holds everything up. HTML is that frame for a webpage.

CSS adds the paint and decoration. JavaScript makes things interactive. But HTML comes first, always.

## What HTML Looks Like

HTML uses things called tags. A tag looks like this: `<h1>`. Tags come in pairs — an opening tag and a closing tag:

```html
<h1>Hello World</h1>
```

The `<h1>` is the opening tag. The `</h1>` is the closing tag (notice the slash). The text in between is the content. The tag is saying: "This text is a big heading."

`h1` means Heading Level 1 — the biggest, most important heading.

## Activity: Build Your First Page

**Step 1:** Open File Explorer and go to Desktop > myproject.

**Step 2:** Right-click on `index.html` and choose "Open with" > Notepad.

**Step 3:** Type this into Notepad — type it, don't paste it. Typing it helps it stick:

```html
<h1>Hello World</h1>
```

**Step 4:** Save the file (Ctrl + S).

**Step 5:** Go back to File Explorer. Double-click `index.html`.

Your browser opens. You should see a big, bold "Hello World" at the top of the page.

That is a real webpage. Running on your computer. Made by you.

## Why `index.html`?

Every website has a main page. By convention, that main page is always named `index.html`. When you go to a website like `example.com`, the server automatically loads `index.html` behind the scenes. You've been seeing `index.html` files your whole life — you just didn't know it.

## Quick Recap

- HTML is the structure of every webpage.
- Tags like `<h1>` wrap content to give it meaning.
- Tags come in pairs: opening `<h1>` and closing `</h1>`.
- `index.html` is the standard name for a website's main page.
- You just made a real webpage.
