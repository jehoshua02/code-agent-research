## What You Learned

**The fundamentals:**
- Computers follow instructions exactly. Bugs are bad instructions, not bad computers.
- Code is text, written in a precise language.
- File extensions tell the computer how to treat a file.

**The terminal:**
- Open it with Win + R > cmd.
- Navigate with `cd` and `cd ..`.
- See files with `dir`.
- Create folders with `mkdir`.

**HTML:**
- Write tags like `<h1>`, `<p>`, and `<b>`.
- Create a real webpage that opens in a browser.
- Understand that every website starts with HTML.

**Python:**
- Run Python in the browser.
- Use `print()` to output text and numbers.
- Understand what variables are and why they exist.

**Git and GitHub:**
- Install Git and configure your name and email.
- Initialize a repo with `git init`.
- Commit code with `git add .` and `git commit -m "message"`.
- Push to GitHub with `git push`.

That's not nothing. That's a real foundation.

## Activity: Finish Strong

Let's add a README to your project. A README is a description of what a project is. Every real project on GitHub has one.

**Step 1:** Open your terminal and go to your project:

```
cd Desktop\myproject
```

**Step 2:** Create a README file:

```
type nul > README.md
```

**Step 3:** Open `README.md` in Notepad. Write one sentence about your project. Something like:

```
This is my first coding project. I made it while learning to code.
```

**Step 4:** Save it. Now commit and push:

```
git add .
git commit -m "add README"
git push
```

**Step 5:** Refresh your GitHub repo page. The README shows up automatically on the repo homepage.

Your project is live. It has a description. It's pushed to GitHub.
