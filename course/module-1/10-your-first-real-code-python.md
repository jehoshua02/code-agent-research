# Lesson 1.10 — Your First Real Code (Python)

## The Big Idea

Python is a programming language. It's one of the most popular languages in the world and one of the best for beginners because it reads almost like English.

Today you're going to run your first real Python code. No setup required — we're using the web.

## Why Python?

A few reasons:

- It's used everywhere: web apps, AI, data science, game scripts, automation.
- The syntax (the rules of the language) is clean and simple.
- Error messages are actually readable.
- It's what a lot of schools and bootcamps start with.

You made HTML in the last few lessons. HTML isn't really code — it just describes content. Python is real code. It actually runs and does things.

## The `print` Function

The most basic thing you can do in Python is print something to the screen.

```python
print("Hello!")
```

That line tells Python: show the text `Hello!` on the screen. Simple.

`print` is a function — a built-in command that does something. The thing in the parentheses is what you're passing to it. The quotes mean it's text.

## Activity: Run Code in the Browser

We're not installing Python today. Instead, we'll use the browser.

**Step 1:** Open your browser and go to:

```
https://www.python.org/shell/
```

This is an official Python shell. It runs Python right in the browser. No setup.

**Step 2:** Click inside the black box. You'll see `>>>` — that's Python waiting for you.

**Step 3:** Type this exactly and press Enter:

```python
print("Hello!")
```

You should see `Hello!` appear on the next line.

**Step 4:** Try it with your name:

```python
print("My name is Alex")
```

**Step 5:** Try printing a number:

```python
print(42)
```

Notice: no quotes around `42`. Numbers don't need quotes.

**Step 6:** Try doing math:

```python
print(10 + 5)
```

Python calculated `15` and printed it. You just used Python as a calculator.

## What Just Happened

You gave Python instructions. Python followed them exactly. The computer did not care what you printed — it just printed whatever you told it to.

That's the same idea from Lesson 1. Computers are dumb. But now you know how to give them the right instructions.

## Quick Recap

- Python is a beginner-friendly programming language.
- `print()` outputs text or numbers to the screen.
- Text goes in quotes. Numbers don't need quotes.
- You can run Python in the browser at python.org/shell.
