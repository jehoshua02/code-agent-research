# Lesson 1.03 — File Types Are Like Costumes

## The Big Idea

A file extension is like a costume. It tells the computer how to treat the file — what app to open it with, and what the contents mean.

Change the costume, and the computer treats the file differently. Even if the contents are the same.

## Think About It This Way

Imagine you show up to school in a chef's uniform. Everyone assumes you know how to cook.

Now you go home, change into a doctor's coat, and come back. Same you. Same knowledge. But now everyone assumes you're a doctor.

File extensions work the same way. The content inside might be identical — but the extension changes how the computer treats it.

- `.txt` — plain text, open in Notepad
- `.html` — a webpage, open in a browser
- `.py` — Python code, run with Python
- `.mp3` — audio, play in a music app

## Important: Windows Might Hide Extensions

By default, Windows hides file extensions. That means `hello.txt` might just show up as `hello`.

Let's fix that so you can see what's actually going on.

**Step 1:** Open File Explorer (the folder icon in your taskbar).

**Step 2:** Click the View tab at the top.

**Step 3:** Check the box that says "File name extensions."

Now you can see the full name of every file, including the extension.

## Activity: Turn a Text File Into a Webpage

Here is something wild. You can rename a text file and make the browser think it's a webpage.

**Step 1:** Find `hello.txt` on your Desktop (from last lesson).

**Step 2:** Right-click it and choose Rename.

**Step 3:** Change `hello.txt` to `hello.html`. Press Enter. If Windows asks if you're sure, say yes.

**Step 4:** Double-click `hello.html`. It should open in your web browser.

What do you see? Probably just your name on a blank white page. Not fancy — but that's a real webpage. Your browser read the file just like it reads every website you visit.

The content didn't change. Only the costume changed. And the computer treated it completely differently.

## What This Teaches You

When you're coding, the extension matters a lot. If you save your Python code as `script.txt` instead of `script.py`, nothing will run. The computer won't know what to do with it.

Always use the right extension for the right type of file.

## Quick Recap

- File extensions are like costumes — they tell the computer what a file is.
- `.txt` = text, `.html` = webpage, `.py` = Python code.
- Windows hides extensions by default. Turn that setting off.
- Same content, different extension = treated completely differently.
