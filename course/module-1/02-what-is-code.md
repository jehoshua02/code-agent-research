# Lesson 1.02 — What Is Code?

## The Big Idea

Code is just instructions — written in a language the computer understands.

That's it. There's no magic. Code is text. Specifically, it's text written in a very precise way so the computer knows exactly what to do.

## Think About It This Way

You already know what a recipe is. A recipe is a list of instructions:

1. Preheat oven to 375 degrees.
2. Mix flour and sugar in a bowl.
3. Add two eggs.

Code works the same way. It's a recipe for the computer. Each line is a step. The computer reads them top to bottom and does what they say.

The difference is the language. A recipe is written in English. Code is written in languages like Python, JavaScript, or HTML — languages designed to be exact and unambiguous.

## Why Can't Computers Just Read English?

English is messy. "Grab me something to drink" could mean a hundred different things depending on context. Computers can't handle that ambiguity.

Programming languages are strict. Every word means one specific thing. Every symbol matters. A missing comma can break everything.

That strictness is annoying to learn at first — but it means the computer always knows exactly what you meant.

## Code Is Just a Text File

Here is something that surprises a lot of people: code is stored in plain text files. Just like your `myname.txt` file from last lesson.

The difference is the file extension — the part after the dot. A file that ends in `.py` is Python code. A file that ends in `.js` is JavaScript. The extension tells the computer (and you) what kind of instructions are inside.

## Activity: Look at Your File From a New Angle

Remember `myname.txt` from last lesson? Let's rename it.

**Step 1:** Find `myname.txt` on your Desktop.

**Step 2:** Right-click it and choose Rename.

**Step 3:** Change the name to `hello.txt`.

**Step 4:** Press Enter.

Look at the file. It still has the same content — your name. But now it's called `hello.txt`.

The `.txt` at the end is called the file extension. It tells the computer: "This is a plain text file." Right now that's what it is.

In the next lesson, you'll see what happens when you change that extension to something else.

## Quick Recap

- Code is instructions written in a precise language.
- Computers need exact instructions because they can't guess.
- Code lives in plain text files.
- The file extension says what kind of code (or content) is inside.
