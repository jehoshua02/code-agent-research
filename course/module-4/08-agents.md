# Lesson 4.08 — Agents: AI That Takes Actions

## The Big Idea

So far, everything you've used AI for has been question-and-answer. You ask. It responds. You ask again.

An **agent** is different. It doesn't just answer — it does things.

An AI agent can search the web, read files, write code, run that code, check the result, and try again — all on its own, without you doing each step.

---

## Do This First

Go to perplexity.ai (it's free).

Ask it a research question that requires multiple sources. Something like:

> "What are the best free tools for building a web app in 2024? Compare at least three options."

Watch what happens. It doesn't just generate text from memory. It:

- Searches the web in real time
- Pulls from multiple sources
- Combines the information into an answer
- Shows you where the info came from

That's an agent in action. It took a goal and figured out the steps to reach it.

---

## What Makes Something an Agent

A regular AI chat:
- You give input
- AI gives output
- Done

An agent:
- You give a goal
- AI plans the steps
- AI uses tools to complete each step
- AI checks the result and adjusts
- AI reports back when done (or asks if stuck)

---

## The Tools Agents Use

Agents can be connected to different tools depending on how they're built:

- **Web search** — finding current information
- **Code execution** — running Python, checking output
- **File access** — reading and writing files on your computer
- **Email or calendar** — scheduling, sending messages
- **APIs** — talking to other apps and services

The AI decides which tool to use and when, based on the goal you give it.

---

## A Real Example

Imagine you ask an agent: "Research the top 5 Python libraries for data visualization and write a summary doc."

A basic AI gives you a list from memory (possibly outdated).

An agent:
1. Searches the web for current rankings
2. Visits a few pages to read details
3. Compares the libraries
4. Writes the summary document
5. Saves it to a file

Same goal. Completely different process.

---

## Why This Changes Everything

Agents handle tasks that used to require you to manually do each step. You set the goal. The agent figures out the path.

This is where AI is heading fast. Knowing how agents work — even at a high level — puts you ahead.

---

## Key Takeaway

Agents are AI that act, not just answer. They use tools, loop through steps, and complete goals without you doing each piece manually. Perplexity is a simple example. Much more powerful versions are already being used in real software.
