# Windsurf

## What It Is

**Windsurf** is an AI-native code editor — and a family of IDE plugins — built by **Codeium**. It is the primary consumer-facing product of Codeium, rebranded from the Codeium Editor to "Windsurf" in **October 2024**. As of **April 2025**, the Codeium company itself rebranded to Windsurf.

- **Product category:** AI-native IDE (standalone editor) + IDE plugins for 40+ editors
- **Maker:** Windsurf (formerly Codeium), founded 2021 by Varun Mohan and Douglas Chen
- **Initial release:** Windsurf editor launched October 2024; Codeium plugin predates this
- **Acquisition history:**
  - May 2025: OpenAI announced a ~$3B acquisition of Codeium/Windsurf; deal collapsed (Microsoft's contractual rights made it unworkable). Google separately licensed Windsurf technology.
  - December 2025: **Cognition AI** (makers of Devin) acquired Windsurf for ~$250M. Plans to merge Windsurf IDE capabilities with Devin for fully autonomous development workflows.

## Pricing

- **Free** — $0/month; unlimited Tab autocomplete, limited Cascade credits, SWE-1 Lite access
- **Light** — credit-based, daily/weekly refresh; access to premium models
- **Pro** — $20/month; unlimited usage at API price, Tab, Previews, Deploys, all premium models, SWE-1.5
- **Max** — $200/month; highest usage limits, Devin Cloud background sessions, priority support
- **Teams** — $40/user/month; admin dashboard, analytics, RBAC, volume discounts
- **Enterprise** — custom pricing; hybrid deployment options, SCIM, account management
- Credit add-ons: $120 per 1,000 pooled credits (don't expire, persist across billing cycles)
- Credits consumed per Cascade message using premium models; base rate 1 credit/message, varies by model

## What It Does

### Core Capabilities

- **Cascade** — the central agentic AI system; takes sequences of actions across your entire codebase without you manually specifying files. Understands repository structure, selects relevant context automatically, executes multi-step tasks including running terminal commands, reading output, and iterating.
- **Flows** — a model that blends inline copilot completions and full agent behavior in one continuous experience. The AI maintains persistent session context, improving over the course of a working session.
- **Windsurf Tab** — AI-powered autocomplete, available on all tiers. Powered by SWE-1-mini; predicts next edits rather than just next tokens.
- **Codemaps** — AI-generated, interactive visual maps of codebase structure. Shows execution flow, grouped sections, component relationships, and trace paths. Clickable nodes navigate directly to source. Shareable via browser links. Generated by a specialized agent using SWE-1.5 or Claude Sonnet. Referenced in Cascade via @-mention for contextual AI conversations.
- **Previews** — in-editor live preview pane for web applications; no browser switching required.
- **Deploys** — one-prompt deployments to Netlify with subdomain management; 5 deploys/day on Pro.
- **Cascade Hooks** — reusable markdown-defined workflow commands (e.g., "lint, test, and deploy to staging") that save and replay multi-step operations.
- **Multi-file editing** — edits, renames, moves, and refactors across multiple files in one operation.
- **Terminal integration** — runs shell commands, reads stdout/stderr, reasons about failures, retries.
- **Codebase-wide search and context** — indexes the entire repo; no manual file tagging needed.
- **Fast Context** — available on Pro; accelerates context retrieval across large codebases.

### Supported Languages and Frameworks

Windsurf supports all languages that VS Code supports (it is built on a VS Code foundation), which covers virtually all mainstream languages. Specific documented support includes:

- Python (with Windsurf Pyright, a Pylance alternative)
- JavaScript / TypeScript
- Java, Kotlin, Go, Rust, C, C++, C#
- Ruby, PHP, Swift
- All languages covered by SWE-Bench test suites

No framework-specific restrictions are documented; the editor is language-agnostic.

### Plugin Support (non-Windsurf editors)

Windsurf provides plugins for **40+ editors**, including:

- JetBrains IDEs (IntelliJ, PyCharm, WebStorm, Rider, GoLand, CLion)
- Vim / NeoVim
- Xcode
- Emacs

Plugin functionality is more limited than the full Windsurf editor (primarily Tab autocomplete and some Cascade access, not full Flows/Codemaps).

## What It Doesn't Do

- **No offline / air-gap mode** — all AI features require internet connectivity. Cloud-only for AI inference. Automatic disqualifier for strict air-gap compliance environments (though Enterprise offers hybrid deployment).
- **No local model execution** — cannot run models on-device; no local LLM support as of early 2026.
- **JetBrains plugin limitations** — remote SSH development via JetBrains Gateway is unsupported. Known bugs exist (e.g., keybinding conflicts in Rider on Windows).
- **Context window degradation** — as sessions grow long, earlier context may be silently dropped; performance degrades without warning.
- **No transparent credit accounting on Free** — the Free tier has undisclosed daily/monthly caps; users cannot predict when limits are hit.
- **No native Git GUI** — unlike full IDEs (JetBrains), Windsurf has no built-in visual git interface; relies on terminal or VS Code's native git panel.
- **Codemaps limited to Pro+** — not available on Free tier.
- **No background agent on Free/Pro** — Devin Cloud background sessions (truly autonomous background development) are Max-tier only.
- **Not open source** — the editor and all SWE-1 models are proprietary.

## Architecture

### Editor Foundation

Windsurf is a **VS Code fork** (like Cursor). It ships as a standalone desktop application with a full VS Code-compatible extension ecosystem. Most VS Code extensions install and run inside Windsurf without modification.

### How AI Runs

- **Cloud inference only** — all model calls go to Windsurf's servers (or third-party API providers). No local inference.
- **BYOK (Bring Your Own Key)** — Free and paid users can supply their own Anthropic or OpenAI API keys for select models, bypassing Windsurf's credit system.
- **Model routing** — the "Adaptive" model option automatically routes requests to the best model for the task type.

### Security and Compliance

Enterprise tier: SOC 2, HIPAA, FedRAMP/DOD, ITAR compliance. RBAC and SCIM provisioning. Hybrid deployment options (not full air-gap).

## Key Differentiators

1. **Agentic-first by design** — Cascade and Flows treat the AI as a peer that takes initiative, not a feature that responds to prompts. Codebase-level context is automatic, not manual.
2. **Proprietary SWE models** — the SWE-1.x family is trained specifically for software engineering, not adapted from general-purpose LLMs. This enables competitive performance at lower per-token cost.
3. **Codemaps** — visual, AI-generated codebase maps are a unique feature with no direct equivalent in Cursor or Copilot. Bridges the gap between AI reasoning and human comprehension of large repos.
4. **Breadth of editor support** — 40+ editor plugins vs. Cursor's VS Code-only approach. Developers using JetBrains, Vim, or Xcode can use Windsurf without switching editors.
5. **Flows model** — blends copilot and agent in a single UX; no mode-switching between "ask" and "do" like Cursor requires.
6. **Enterprise compliance depth** — SOC 2 + HIPAA + FedRAMP + ITAR in one product; Cursor offers only SOC 2.
7. **Free tier with real capability** — SWE-1 Lite and unlimited Tab autocomplete at $0; competitors' free tiers are more restrictive.
8. **Deploys integration** — built-in Netlify deploy pipeline directly from Cascade; no external CI setup needed for simple web projects.
9. **Post-Cognition roadmap** — Cognition plans to integrate Windsurf with Devin for fully autonomous background development, a direction no current competitor has shipping product for.

## Ideal Use Cases

- **Full-stack web developers** who want an autonomous coding partner that manages context, edits across files, and deploys — all without leaving the editor.
- **Teams onboarding to large codebases** — Codemaps significantly reduces ramp-up time by generating visual execution-flow documentation automatically.
- **Enterprise engineering orgs** needing compliance (HIPAA, FedRAMP, ITAR) plus AI-native tooling in one product.
- **Polyglot developers** who split time across VS Code, JetBrains, and Vim — Windsurf's plugin breadth supports this without fragmentation.
- **Developers who prefer agentic autonomy** — those who want to describe a goal and let the AI execute multiple steps unattended, vs. reviewing every suggestion interactively (Cursor's model).
- **Solo developers and indie hackers** — the Free tier's Tab autocomplete and limited Cascade access provide real value at $0; Pro at $20/month is competitive for heavy users.
- **Teams wanting built-in deploy pipelines** — Windsurf's Netlify integration and Cascade Hooks enable repeatable deploy workflows without external tooling.

**Less ideal for:**
- Air-gapped or fully offline environments
- Teams requiring all tooling to be open source
- Developers deeply invested in JetBrains remote SSH workflows

### Open Source Status

Windsurf (the editor) is **proprietary and closed source**. The SWE-1 model family is also proprietary.

The Codeium/Windsurf plugin for VS Code and other editors was historically open source in early form (GitHub: `Exafunction/codeium`), but the current Windsurf product line is not.

### Extensibility

- **VS Code extension compatibility** — because Windsurf is a VS Code fork, the majority of VS Code marketplace extensions work inside it. Developers do not need to port tooling.
- **BYOK** — custom model keys allow power users to route to their own Claude or OpenAI subscriptions.
- **Cascade Hooks** — markdown-defined custom workflows act as a lightweight scripting layer for repeated tasks.
- **Codemaps API** — Codemaps are shareable via browser links; team members without the editor can view them.
- **MCP (Model Context Protocol)** — Windsurf supports MCP for extending Cascade with external tools and data sources.
- **Rules files** (`windsurf_rules`) — per-project instruction files that shape Cascade's behavior, analogous to Cursor's `.cursorrules`.
