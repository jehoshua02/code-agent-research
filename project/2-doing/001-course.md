## Details

Target audience: 13-year-old, no code exposure, just YouTube and games. Assume no prior knowledge.

Personal project, shared with specific audience. Markdown docs only. Claude drafts all content.

4 modules, ~10-15 lessons each:

1. **Code Basics** — What code is, terminal, files, git. Hands-on from lesson 1.
2. **How AI Works** — What LLMs are, tokens, prompts, context. Demystified, no math.
3. **AI Coding Tools** — Categories (CLI, IDE, extensions), trying one tool, writing first app with AI.
4. **Going Deeper** — Models, choosing tools, prompt engineering, building real projects.

Design principles:
- Each lesson = one concept + one thing to try
- "Do first, explain after"
- Teach concepts and categories, not all 15 tools
- No walls of text
- 2-5 minutes per lesson
